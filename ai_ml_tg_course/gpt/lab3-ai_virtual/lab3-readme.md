Step 3.1: Enable Vector Support in PostgreSQL
Standard databases are good at finding "Production-RG." AI databases are good at finding "The resources I use for the customer-facing website." To do this, we need pgvector.

1. Enable the extension in Azure
Azure Postgres Flexible Server has the vector extension built-in, but it is disabled by default for security.

Run this command:

az postgres flexible-server parameter set ^
  --resource-group rg-finops-prod-data ^
  --server-name finops-pgflex ^
  --name azure.extensions ^
  --value "VECTOR"

  Portal -> Flexiserver -> Setting -> Server Parameters -> azure.extentions -> Check VECTOR must be selected 


  2. Create the Vector Schema
We need a new table to store the "Knowledge" of your cloud. Create a file named lab3-init.yaml:

apiVersion: batch/v1
kind: Job
metadata:
  name: finops-vector-init
  namespace: platform
spec:
  template:
    spec:
      containers:
      - name: psql
        image: postgres:16-alpine
        env:
        - name: PGPASSWORD
          value: "YourStr0ngPass!"
        command: ["sh", "-c"]
        args:
        - |
          psql -h finops-pgflex.postgres.database.azure.com -U pgadmin -d finops-db <<EOF
          CREATE EXTENSION IF NOT EXISTS vector;
          
          -- Table to store resource metadata for the AI to "read"
          CREATE TABLE IF NOT EXISTS resource_embeddings (
              id SERIAL PRIMARY KEY,
              resource_id TEXT UNIQUE,
              content TEXT, -- Human readable description
              embedding vector(1536) -- 1536 is the standard for OpenAI embeddings
          );
          EOF
      restartPolicy: OnFailure
